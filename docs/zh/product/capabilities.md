# 能力与应用

本页介绍 W1 的移动、感知和焊接作业方向。数值参数见[型号与规格](./specifications.md)，软件调用条件见 [ROS 2 接口示例](../sdk/ros2-example.md)。

## 移动与感知

| 能力           | 描述                                                                                    | 
| -------------- | ----------------------------------------------------- |
| 双足移动       | 跨越障碍、适应狭窄船舱，自主导航、避障及上下楼梯                                        | 
| 环境与工件感知 | 使用激光雷达、ToF 相机及 3D 线扫相机感知环境和工件，数量见[部件与接口](./interfaces.md) | 
| 焊缝处理       | 寻找、识别焊缝，规划轨迹并执行焊接                                                      |

ROS 2 状态与应用服务另见[接口示例](../sdk/ros2-example.md)；传感器物理连接与安装资料见[部件与接口](./interfaces.md)。

## 作业姿态与焊接位置

作业姿态包括站姿、马步蹲姿、半跪姿；焊接位置包括平焊、立焊、仰焊。


## 控制架构

| 层级 | 职责概念            |
| ---- | ------------------- |
| S2   | 任务规划            |
| S1   | 动作规划 / 动作调度 |
| S0   | 运动控制            |
