# 能力与应用

本页介绍 W1 的移动、感知和焊接作业方向。具体性能、适用工况及交付版本尚待确认。数值参数见[型号与规格](./specifications.md)，软件调用条件见 [ROS 2 接口示例](../sdk/ros2-example.md)。

## 移动与感知

| 能力           | 描述                                                                                    | 
| -------------- | ----------------------------------------------------- |
| 双足移动       | 跨越障碍、适应狭窄船舱，自主导航、避障及上下楼梯                                        | 
| 环境与工件感知 | 使用激光雷达、ToF 相机及 3D 线扫相机感知环境和工件，数量见[部件与接口](./interfaces.md) | 
| 焊缝处理       | 寻找、识别焊缝，规划轨迹并执行焊接                                                      |

硬件感知配置不直接定义对外数据话题或 SDK 功能。ROS 2 状态与应用服务另见[接口示例](../sdk/ros2-example.md)；传感器物理连接与安装资料见[部件与接口](./interfaces.md)。

## 作业姿态与焊接位置

作业姿态包括站姿、马步蹲姿、半跪姿；焊接位置包括平焊、立焊、仰焊。

各姿态的工作空间、稳定性条件、焊接工艺和连续作业时长仍待补充。后续需按姿态与工况记录性能，不能据此推算焊接精度、重复定位精度或质量合格率。
