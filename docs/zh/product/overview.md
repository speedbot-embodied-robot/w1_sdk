# 产品概览

W1（Weldroid-W1）是视比特面向船舶制造等复杂焊接场景推出的全尺寸双足人形机器人。其产品方向是在狭窄作业空间中移动到工位，感知工件与焊缝，并完成焊接任务。

正式对外名称、硬件修订与能力适用条件仍需确认。参考参数及其条件说明见[型号与规格](./specifications.md)。

## 产品定位与场景

| 项目     | 内容                                                         |
| -------- | ------------------------------------------------------------ |
| 产品形态 | 全尺寸双足人形焊接机器人                                     |
| 面向场景 | 船舶制造，尤其是空间狭窄、结构复杂的船舱等作业区域           |
| 作业方向 | 移动到工位、感知环境与工件、寻找焊缝、规划轨迹并执行焊接     |
| 文档读者 | 需要了解 W1 产品、读取机器人状态或对接规划与焊接流程的开发者 |

移动能力、姿态、感知配置和应用进度另见[能力与应用](./capabilities.md)；工艺范围、工作环境和性能验收条件仍待补充。

## 适用型号与接口范围

W1 产品名称与各硬件修订的对应清单仍待补充。本站的 [ROS 2 接口示例](../sdk/ros2-example.md)和[整机控制参考](../api/w1-control.md)则明确面向 `speed_W1_v1.2`、28 个受控轴和七轴双臂。

产品参考资料的全身自由度与软件受控轴数量存在差异，见[型号与规格](./specifications.md)。接入软件时，以对应机型的已安装配置和接口说明为准；产品描述的适用版本需逐项确认。

## 开发者可以从哪里开始

| 任务                     | 所需配置                                                       | 可检查的结果                                                                                   |
| ------------------------ | -------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| 读取关节反馈与 PVT 状态  | ROS 2 Humble、本站 `w1_docs_ros2` 读端、已启动的 W1 工作区端点 | 按名称读取右肘角度，获得 PVT 服务的 `success/message`；见 [ROS 2 示例](../sdk/ros2-example.md) |
| 请求单臂规划             | W1 Planner、`speedbot_msgs` 与对应规划场景                     | 用 `/plan_move` 和 `execute=false` 查询规划结果、轨迹及场景版本；见同页的规划示例              |
| 了解焊接程序生成接入     | W1 视觉节点、TeachPanel、相机、实测标定与有效 TCP              | 查看 Capture/Build 的调用条件、程序路径及长度字段；见同页的焊接服务说明                        |
| 测试语言工具链和代码调用 | Python 3.10+，或 C++17 与 CMake                                | 使用独立的[可运行示例](../sdk/examples.md)检查数据校验和调用方式                               |

本站客户端测试验证了隔离端点下的读取与错误处理。W1 控制器、规划、相机和焊接运行需要相应工作区及设备条件，不能用客户端测试结果代替整机验收。安装与交付版本信息继续维护在 [SDK 集成](../sdk/integration.md)。
