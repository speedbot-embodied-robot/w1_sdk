# 产品概览

W1（Weldroid-W1）是视比特面向船舶制造等复杂焊接场景推出的全尺寸双足人形机器人。其产品方向是在狭窄作业空间中移动到工位，感知工件与焊缝，并完成焊接任务。

参考参数及其条件说明见[型号与规格](./specifications.md)。

## 产品定位与场景

| 项目     | 内容                                                         |
| -------- | ------------------------------------------------------------ |
| 产品形态 | 全尺寸双足人形焊接机器人                                     |
| 面向场景 | 船舶制造，尤其是空间狭窄、结构复杂的船舱等作业区域           |
| 作业方向 | 移动到工位、感知环境与工件、寻找焊缝、规划轨迹并执行焊接     |
| 文档读者 | 需要了解 W1 产品、读取机器人状态或对接规划与焊接流程的开发者 |

移动能力、姿态、感知配置和应用进度另见[能力与应用](./capabilities.md)。

## 适用型号与接口范围

本站的 [ROS 2 接口示例](../sdk/ros2-example.md)和[整机控制参考](../api/w1-control.md)面向正式 `speed_W1_v1.2` 配置，包含 26 个受控关节和每侧 6 轴双臂。

规格页所列全身自由度与软件受控关节数属于不同参数，见[型号与规格](./specifications.md)。软件接入以对应机型的已安装配置和接口说明为准。

## 开发者可以从哪里开始

| 任务                     | 所需配置                                | 可检查的结果                                                                   |
| ------------------------ | --------------------------------------- | ------------------------------------------------------------------------------ |
| 读取关节和 IMU 反馈      | ROS 2 Humble、已启动的 W1 工作区端点    | 按名称读取关节状态并解析 IMU 消息；见 [ROS 2 示例](../sdk/ros2-example.md)     |
| 查看双臂示教接口         | 已加载 W1 示教面板的系统                | 核对 `/arm_move` 的单臂和双臂目标格式；见 [ROS 2 示例](../sdk/ros2-example.md) |
| 查看控制数组布局         | ROS 2 Humble、正式 `speed_W1_v1.2` 配置 | 核对 26 轴数组顺序、数据块和命令话题；见 [整机控制接口](../api/w1-control.md)  |
| 测试语言工具链和代码调用 | Python 3.10+，或 C++17 与 CMake         | 使用独立的[可运行示例](../sdk/examples.md)检查数据校验和调用方式               |

关节、IMU 与控制接口示例说明 ROS 2 消息的读取和数据布局。设备状态流是否存在取决于相应真机发布器和监控节点。安装环境信息见 [SDK 集成](../sdk/integration.md)。
