# 可运行示例

仓库提供 Python 关节反馈录制器和 C++17 数据校验示例。W1 的 ROS 2 页面说明状态话题、真实机器人 IMU 与电机诊断接口、26 轴命令布局及双臂示教接口。

| 示例                          | 输入与输出                              | 重点                                       | 所需环境                                      |
| ----------------------------- | --------------------------------------- | ------------------------------------------ | --------------------------------------------- |
| [Python](./python-example.md) | 订阅 `/joint_states`，录制反馈 JSONL    | ROS 2 订阅、消息数组语义、时间戳与文件记录 | Python 3.10、ROS 2 Humble、rclpy、sensor_msgs |
| [C++](./cpp-example.md)       | 校验人工构造的状态                      | RAII、所有权、错误处理、CMake target       | C++17、CMake                                  |
| [W1 ROS 2](./ros2-example.md) | 读取关节与 IMU 状态，查看电机和控制接口 | 消息字段、QoS、26 轴顺序、示教话题         | ROS 2 Humble；接入 W1 需已启动的设备工作区    |

Python 录制器用于保存收到的关节反馈。C++ 示例使用人工构造的数据。ROS 2 页面中的关节与 IMU 读端示例订阅公开话题，控制话题格式按公开数据布局说明。

Python 录制器和 W1 ROS 2 页从仓库内的示例源码导入代码，中英文页面使用同一实现。一般 C++ 库示例在对应文档页维护。
