# 可运行示例

Python 示例使用 ROS 2 Humble 订阅 W1 的 `/joint_states` 并将反馈录制为 JSONL；C++ 示例使用人工构造的状态，展示语言和库接口。ROS 2 指南还介绍单次关节读取、PVT 查询，以及规划、示教和焊接接口。

| 示例                          | 输入与输出                               | 重点                                         | 所需环境                                                                      |
| ----------------------------- | ---------------------------------------- | -------------------------------------------- | ----------------------------------------------------------------------------- |
| [Python](./python-example.md) | 订阅 `/joint_states`，录制关节反馈 JSONL | ROS 2 订阅、消息数组语义、采集时间与文件记录 | Python 3.10、ROS 2 Humble、rclpy、sensor_msgs、std_srvs；连接 W1 需 W1 工作区 |
| [C++](./cpp-example.md)       | 构造人工状态，通过库接口校验             | RAII、所有权、显式错误、库与调用程序分离     | C++17、CMake                                                                  |
| [W1 ROS 2](./ros2-example.md) | 单次读取关节状态并查询 PVT               | 按关节名匹配、QoS、异步服务、超时与退出      | ROS 2 Humble、rclpy、sensor_msgs、std_srvs；接入需 W1 工作区                  |

## 建议测试顺序

先按 Python 页面构建 ROS 2 包，再运行录制器连接已运行的 W1 `/joint_states` 发布端；没有 W1 环境时，可运行 C++ 示例并按 ROS 2 页面执行隔离端点测试。隔离测试只验证客户端与测试端点的收发，不运行 W1 控制器或模拟硬件行为。

Python 和 C++ 是两个独立示例，不包含跨语言绑定。ROS 2 示例使用 Python 客户端库，ROS 消息类型才是跨语言节点之间的接口契约。

## 代码展示与维护

每页的代码直接导入仓库 examples/ 下的真实源文件，中英文展示同一份实现。

网页是静态文档，示例在你的开发机或 CI 中运行。
