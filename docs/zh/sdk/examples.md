# 可运行示例

Python 与 C++ 示例使用人工构造的关节状态，帮助你测试语言特性和运行方式。ROS 2 示例已按 W1 实际接口文档接入，展示状态订阅与 PVT 服务查询，并提供规划、示教和焊接接口的调用说明。

| 示例                          | 输入与输出                          | 重点                                        | 所需环境                                                           |
| ----------------------------- | ----------------------------------- | ------------------------------------------- | ------------------------------------------------------------------ |
| [Python](./python-example.md) | 读取 JSON，校验并输出结构化结果     | 类型提示与运行时检查、不可变数据、异常、CLI | Python 3.10+，标准库                                               |
| [C++](./cpp-example.md)       | 构造类型化状态，通过库接口校验      | RAII、所有权、显式错误、库与调用程序分离    | C++17、CMake                                                       |
| [W1 ROS 2](./ros2-example.md) | 读取 `/joint_states`，查询 PVT 状态 | 按关节名匹配、QoS、异步服务、超时与退出     | ROS 2 Humble、rclpy、sensor_msgs、std_srvs；在线接入另需 W1 工作区 |

## 建议测试顺序

先运行 Python 和 C++，确认本机语言工具链正常，再按 ROS 2 教程构建只读客户端。已有 W1 工作区时，可连接隔离 mock 读取反馈并查询 PVT；仅安装标准 Humble 时，可运行仓库测试验证客户端的收发和错误处理。测试替身不包含 W1 控制器逻辑。

Python 和 C++ 是两个独立示例，不包含跨语言绑定。ROS 2 示例使用 Python 客户端库，ROS 消息类型才是跨语言节点之间的接口契约。

## 代码展示与维护

每页的代码直接导入仓库 examples/ 下的真实源文件，中英文展示同一份实现。网页代码块支持高亮和复制；代码注释及程序输出保持源码原文。

修改源文件后重新构建即可更新代码展示。正文的参数说明、命令和行为描述仍需人工同步。网页是静态文档，示例在你的开发机或 CI 中运行。

## 接入真实 W1

W1 `speed_W1_v1.2` 的 ROS 2 接口见 [W1 ROS 2 示例](./ros2-example.md)和 [W1 整机控制参考](../api/w1-control.md)。SDK 安装与交付版本信息仍由 [SDK 集成](./integration.md)维护。在线接入前核对已安装配置、运行机型、ROS 域和端点 QoS。
