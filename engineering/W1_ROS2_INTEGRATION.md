# W1 ROS 2 实际接口集成

日期：2026-11-20。

## 目标与资料

将 SDK 中原来演示虚构 JointState 的 ROS 2 教程替换为 W1 实际接口示例，并保留 IDE 风格代码展示。输入资料为 `tmp/W1_ROS2通讯接口示例.md` 与 `tmp/整机控制接口README.md`。前者明确声明 W1 七轴双臂的默认插补、令牌和映射优先于通用说明；集成沿用该优先级。原始资料保持不变。

## 实现安排

- `w1_ros2_code`：更新 ROS 2 包、只读状态与服务客户端、隔离端点测试和 CI 依赖。
- `w1_ros2_docs`：替换中英文 ROS 2 教程，新增中英文 W1 整机控制参考。
- `w1_interface_review`：独立核对接口契约、资料矛盾和最终改动。
- 主代理：导航、索引与关联说明整合，执行站点及回归检查，汇总结果。

## 设计约束

主程序订阅 `/joint_states`，按名称读取 `right_elbow_joint`，调用 `/mit_controller/get_pvt_interpolation_status`。使用 ROS 2 Humble 的标准 `sensor_msgs` 和 `std_srvs`，反馈和服务均设超时。程序不发布运动命令。自动化测试以隔离 localhost 话题及服务替身验证客户端行为，不将替身描述为 W1 mock 控制器。

Planner、Teach、Capture 的真实接口以文档与 CLI 示例提供；实际运行依赖另外安装的 W1 工作区、消息包和相应节点。本站不包含驱动、控制 YAML、轨迹或标定文件。涉及旧资料的 `layout` 可空、无插补及任意输入频率等概括，不适用于默认 W1 PVT 会话。

Python 和 C++ 原有独立语言示例保留；用户修改的产品首页与产品资料保持不变。不执行真机动作，不自动推送。

1. ROS 2 构建、消息契约单测、实际 DDS 端点客户端测试，覆盖成功与错误退出。
