# 文档布局调整

2026-11-20：正文加宽，左右目录靠近窗口边缘，让源码和参数表获得更多空间。

## 实现

- VitePress 默认主题负责组件结构与响应式行为，站点通过 `docs/.vitepress/theme/index.ts` 加载自定义样式。
- 新增 `layout.css` 集中管理正文宽度与两侧目录；`style.css` 继续管理配色和首页，`editor.css` 管理源码块外观。
- 桌面宽度从 960px 起，左侧导航 240px、正文取消 688px 上限、外边距 24px；从 1280px 起，右侧目录 200px、与正文间隔 24px。
- 同步覆盖大屏导航栏和内容容器的居中留白公式。取消无效的旧 820px 规则，保留默认手机抽屉、目录折叠和代码块横向滚动。
- 英文顶部菜单在原布局的 768px 宽度下溢出，在 960/1024px 下也超出导航容器。768–1279px 的文档页改用原生折叠菜单，并保留其中的语言和外观控件。

主代理负责实现与浏览器验证；`wide_layout_review` 只读检查默认主题的 CSS 优先级、断点、固定目录宽度以及嵌套 `.content` 选择器，避免误改右侧目录内部布局。

## 验收

检查中英文 ROS 2 示例在 1920、1440、1280、1024、960、768、390px 下的正文与目录位置、代码滚动及整页宽度；手机目录可开关，代码标签和复制仍正常。检查格式、发布路径构建和站内链接。

## 结果

Chrome 浏览器检查中英文的上述七种视口通过：页面无横向溢出；正文与目录不重叠；左栏与顶部标题对齐；右目录 200px，距内容边缘留出 24px。

额外检查英文 1024px 菜单中的页面跳转后恢复滚动，以及菜单打开时切换到 1280px 后关闭遮罩，均通过。
